p. 07Procedure

From sketch to part.

Five phases that repeat in every project, whether it is an injected housing, a robot or an app.

  1. Phase 1

    Research

    Users, context, regulations and competitors. Understand the problem before drawing anything.

  2. Phase 2

    Conceptualise

    Sketches, quick mock-ups and use scenarios. Many cheap ideas to pick a good one.

  3. Phase 3

    Model and validate

    CAD, calculation, manufacturability and rendering, to decide with data and with images.

  4. Phase 4

    Prototype

    3D printing, electronics and clickable interfaces. Test, break and fix.

  5. Phase 5

    Implement

    Drawings and documentation for production, automation or code ready to ship.
